# QSX-UF RTL microarchitecture

Algorithm: DECISIONS.md D1. Graph-specific constant tables are generated by `rtl/gen_graph.py`
(`qsx_graph_defs.svh`, `qsx_graph_tables.svh`); everything else is hand-written, parameterised SystemVerilog
(Yosys/Verilator/slang-compatible subset).

```
 s_axis ──► qsx_ingress ──► dispatcher ──► qsx_uf_core ──► egress ──► m_axis
  (hdr+W)   BRAM ring of      (load W+1       (fabric +      (hdr + CW
            NBUF frame slots   beats, gate     LANES scans)   corr beats)
            commit-on-last,    on cfg)
            tready=!full            ▲
 cfg port ─────────────────► qsx_cfg (atomic BEGIN/WRITE/COMMIT; threshold table; max_rounds; watchdog)
```

## Core (`qsx_uf_core.sv`)
* **Edge fabric** (E edges, fully parallel): `support[e]` (TB-bit saturating counter), `grown[e] = support==thr`,
  one-cycle Jacobi growth `support' = min(thr, support + active[u] + active[v])`.
* **Vertex fabric** (V detectors, fully parallel): `label[v]` (VB bits) min-propagation over grown edges
  (balanced min tree of degree+1 inputs), BFS distance `dst[v]` relaxation, canonical parent-edge selection
  (one-hot lowest edge index), and self-timed peeling (a vertex fires once all children are done).
* **LANES scans** (the compute-unit parameter): cluster parity / boundary accumulation and the activity
  broadcast process LANES vertices per cycle (`2·⌈V/LANES⌉` cycles per round).
* **FSM / cycle model**: `IDLE → LABEL* → PAR(NCH) → ACT(NCH) → CHK → [GROW → LABEL* …] → DINIT → DIST* → PEH → PEEL* → DONE`.
  The cycle count is reproduced exactly by `qsx::HwModel` (decoders/), verified in co-simulation.
* **Safety mechanisms**: `max_rounds` timeout, `cycle_budget` watchdog, structural fail-closed in PEEL,
  correction/obs forced to zero for any status ≠ OK.

## Shell (`qsx_top.sv`)
Input frame: header `{8'hA5, …, tag[15:0]}` + W = ⌈V/32⌉ payload beats. Output frame: header
`{8'h5A, status[3:0], 3'b0, obs, tag[15:0]}` + CW = ⌈E/32⌉ correction beats (OUT_CORR=1).
Status: 0 OK, 1 TIMEOUT, 2 PARITY_ERROR, 3 WATCHDOG, 4 FRAME_ERROR, 5 CFG_INVALID.
Malformed frames (bad magic, short, long) are answered in order with FRAME_ERROR. A configuration
session that misses any threshold word leaves `cfg_ok=0`, so frames are answered CFG_INVALID and never decoded.
